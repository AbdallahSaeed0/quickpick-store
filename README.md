## 🚀 Project Overview

This project is a modern, full-featured e-commerce platform built using a **React** front-end and a **Laravel** (PHP) back-end. It provides a seamless online shopping experience for users, while giving administrators complete control over store content and orders.

---

## 🛒 Key Features

- **Modern Tech Stack**
  - <b>Front-end:</b> React (component-based, fast, and user-friendly)
  - <b>Back-end:</b> Laravel PHP framework (robust, secure, RESTful API)

- **Standard E-commerce Functionality**
  - User registration & authentication
  - Product catalog with categories & search
  - Cart and checkout
  - Order history for customers
  - Payment gateway integration
  - Admin dashboard

- **Advanced Order Management**
  - <b>Edit Orders After Placement:</b> Admins can modify orders after they’ve been created—update products, quantities, customer info, or status as needed.

- **Full Content Control**
  - Dynamic content management: manage images, banners, and text from the admin panel
  - Choose and schedule featured products

- **Admin Tools**
  - Product & category management
  - Inventory control
  - User management
  - Flexible content editor for banners and promotional blocks
  - Analytics and order reports

- **Responsive Design** (mobile, tablet, desktop)
